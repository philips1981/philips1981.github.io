# Marstek Venus E: celspanningen uitlezen

Een kleine webpagina om de celspanningen en andere gegevens van een Marstek Venus E batterij via Bluetooth uit te lezen. Alleen lezen: de pagina stuurt enkel een leescommando en geeft geen oordeel over je batterij.

Werkt in Chrome, Edge en Opera op een computer of Android.

Onofficieel hulpmiddel, niet verbonden met Marstek. Gebruik op eigen risico.

Het protocol is gebaseerd op het onderzoek van [rweijnen/marstek-venus-monitor](https://github.com/rweijnen/marstek-venus-monitor).
